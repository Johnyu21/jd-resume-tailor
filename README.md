# JD Resume Tailor · 本地 AI 岗位简历定制台

一款 **100% 本地运行、隐私安全** 的 AI 岗位简历定向定制工作台：内置 **13 套可自由切换的 HTML 简历模板**，打通 **「JD 采集收件箱 → 项目深度素材库 → 多模型定向改写 → 代码级 Diff 红删绿增审阅 → Golden Set 标杆评测与二轮优化 → 高清 PNG / PDF 导出」** 全流程。

---

## 核心特性

1. **主简历与 AI 副模板严格隔离（多标签工作台）**
   - 固定首标签 `🏠 我的主简历` 受保护，AI 定制绝不覆盖主简历。
   - 每次定向生成自动基于主简历克隆出独立的 `🎯 公司 · 岗位` 副模板标签，支持独立切换 13 套主题，并永久绑定公司名、岗位名、薪资、城市、原岗位链接与历史档案，随时查阅复盘。
2. **代码 Review 级 Diff 对比审阅（红删绿增）**
   - 在任意 AI 副模板上开启 **🔍 Diff 审阅**，实时与主简历逐模块字符级对比（红删 `-` / 绿增 `+`），支持逐条 **还原为主简历 / 移除新增 / 恢复原条目**。
3. **三层取材与防面试露馅机制**
   - 内置 **项目深度素材库** 与 **一键复制「项目深度提炼提示词」**（自动识别系统桌面生成标准项目 MD）。
   - 审核区清晰标注 `原有 / 素材库命中 / JD 改写 / AI 扩展`；其中 **`AI 扩展` 默认不勾选**，并附带不写入简历的 **面试应对要点**。
4. **4 大核心模块独立模型路由（支持统一接口 + 跨供应商覆盖）**
   - 支持拉取 OpenAI 兼容 `/v1/models` 模型目录并标注 `📷` 图片能力。
   - **生成模块 / 评测模块 / 标杆提炼模块 / 视觉识图模块** 各自独立选模型，支持跨平台覆盖独立 Base URL / API Key，并支持运行时快捷 A/B 切换。
5. **Golden Set 标杆库 + LLM-as-a-Judge 独立评测闭环**
   - 支持上传 **PDF / DOCX / HTML / PNG / JPG / WEBP** 高分标杆简历（文档本地解析、图片走视觉模型 OCR 并自动脱敏）。
   - 生成后输出 5 维评分 + 结构化亮点与改进建议，支持 **按评测建议再优化一轮**（带原地计时与一键取消）。
6. **零爬虫、零自动投递安全隔离**
   - 配套油猴脚本（`userscript/boss-jd-capture.user.js`）绝不爬取平台后端接口、绝不自动打招呼或自动投递；仅支持人工单条或 3~6 秒低频模拟点选采集可见 JD 至本地收件箱（最多 200 条，自动去重），同时支持 **Snipaste 截图 `Ctrl+V` 贴图识图**。

## 快速启动

> 前置要求：本机已安装 [Node.js](https://nodejs.org/)（建议 v18+）

### Windows 一键脚本（推荐）
下载解压（或 `git clone`）后，直接双击项目根目录的脚本：
- **`启动简历定制台.bat`**：自动检测 Node.js、首次自动安装依赖、防重复启动并自动打开浏览器 `http://127.0.0.1:3845`。
- **`重启简历定制台.bat`**：一键停止旧服务并重启。
- **`停止简历定制台.bat`**：一键释放 3845 端口停止服务。

### 命令行启动（Windows / macOS / Linux）
```bash
npm install
node server.js
```
启动后浏览器访问：`http://127.0.0.1:3845`

## 快速上手步骤

1. **配置模型**：点击右上角 **✨ AI 岗位定制 → 设置**，填写兼容 OpenAI 协议的 Base URL、API Key，点 **🔄 获取可用模型** 并为生成 / 评测 / 标杆提炼 / 视觉模块分配模型（推荐生成与评测用不同模型）。
2. **建立主简历与素材库**：在 `🏠 我的主简历` 中填好真实经历并保存；可在 **项目素材库** 复制提炼提示词扫描代码仓生成桌面项目 MD 并导入。
3. **采集 JD**：
   - 浏览器打开 `http://127.0.0.1:3845/boss-jd-capture.user.js` 一键安装配套油猴脚本到 Chrome 篡改猴，在招聘页采集 JD 到本地收件箱；
   - 或直接在「JD 定制」抽屉粘贴 JD 文本 / `Ctrl+V` 粘贴 JD 截图识图。
4. **定制、审阅与导出**：生成提案 → 查看多维评测与面试要点 → 勾选生成独立副模板 → 用 **🔍 Diff 审阅** 核对红删绿增 → 顶部 **导出 / 保存** 一键导出 PDF 或高清 PNG 长图。
